🔧 MODIFICATIONS APPORTÉES
================================================================================

1. BASE DE DONNÉES
   ❌ Ancien : 'ClaraVerseDB' version 1
   ✅ Nouveau : 'clara_db' version 12
   
   ❌ Ancien store : 'tablePersistence'
   ✅ Nouveau store : 'clara_generated_tables'

2. MÉTHODE getAll()
   ❌ Ancien : getAll() → toutes les données
   ✅ Nouveau : getAll(sessionId) → données du chat uniquement
   
   Ajout d'un index pour filtrer par sessionId :
   ```javascript
   const index = store.index('sessionId');
   const getAllRequest = sessionId ? index.getAll(sessionId) : store.getAll();
   ```

3. MÉTHODE get()
   ❌ Ancien : get(key)
   ✅ Nouveau : get(id)
   
   Migration vers le nouveau store 'clara_generated_tables'

4. MÉTHODE set()
   ❌ Ancien : set(key, value) → deux paramètres séparés
   ✅ Nouveau : set(table) → objet avec id + sessionId
   
   Assure la présence obligatoire de :
   - id : identifiant unique
   - sessionId : identifiant du chat
   - timestamp : horodatage

5. MÉTHODE remove()
   ❌ Ancien : remove(key)
   ✅ Nouveau : remove(id) + removeBySession(sessionId)
   
   Ajout d'une méthode pour supprimer toutes les tables d'un chat

6. SAUVEGARDE CELLULE
   Ajout automatique du sessionId lors de la sauvegarde :
   ```javascript
   const sessionId = window.currentSessionId || 
                     window.localStorage.getItem('currentChatId') || 
                     'default_session';
   ```
