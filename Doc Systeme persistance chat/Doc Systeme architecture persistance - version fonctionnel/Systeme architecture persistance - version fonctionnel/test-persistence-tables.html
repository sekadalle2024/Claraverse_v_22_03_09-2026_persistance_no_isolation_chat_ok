🧪 Tests de Persistance - ClaraVerse Tables

⚠️ ATTENTION : Ces tests doivent être effectués APRÈS avoir appliqué les modifications du plan d'implémentation.

📋 Test 1 : Ordre des Tables En attente

Objectif

Vérifier que les tables sont toujours dans le bon ordre : Table_conso → Résultat → Modelised

Instructions

  1. Ouvrir ClaraVerse dans un navigateur
  2. Créer ou ouvrir un chat
  3. Générer une table avec colonnes Assertion/Conclusion/Ctr (Modelised_table)
  4. Attendre la génération automatique de la Table_conso et Table Résultat
  5. Ouvrir les DevTools (F12) → Elements
  6. Inspecter l'ordre des tables dans le DOM

💾 Test 2 : Persistance Simple En attente

Objectif

Vérifier que les modifications sont sauvegardées et restaurées après rechargement

Instructions

  1. Modifier des cellules dans chacune des 3 tables
  2. Attendre 2 secondes (debounce de sauvegarde)
  3. Recharger la page (F5 ou Ctrl+R)
  4. Vérifier que toutes les modifications sont restaurées

🔒 Test 3 : Isolation Inter-Chats En attente

Objectif

Vérifier que les tables d'un chat ne contaminent pas un autre chat

Instructions

  1. Chat A : Générer des tables et modifier des cellules
  2. Chat A : Noter les valeurs modifiées
  3. Ouvrir un nouveau chat (Chat B)
  4. Chat B : Générer des tables différentes
  5. Chat B : Vérifier que les valeurs du Chat A n'apparaissent PAS
  6. Retourner au Chat A
  7. Chat A : Vérifier que les valeurs du Chat A sont toujours là

🗄️ Test 4 : Vérification IndexedDB En attente

Objectif

Vérifier que les tables sont correctement enregistrées dans IndexedDB

Instructions

  1. Ouvrir DevTools (F12) → Application → Storage → IndexedDB
  2. Ouvrir la base clara_db
  3. Ouvrir le store clara_generated_tables
  4. Vérifier que les tables y sont enregistrées
