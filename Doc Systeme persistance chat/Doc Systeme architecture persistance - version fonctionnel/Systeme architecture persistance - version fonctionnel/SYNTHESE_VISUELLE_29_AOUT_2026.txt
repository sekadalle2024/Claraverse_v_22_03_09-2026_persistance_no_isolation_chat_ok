Différence npm run dev vs npm run build :

┌─────────────────────────────────────┐
│  npm run dev                        │
│  ────────────────                   │
│  • Compile à la volée              │
│  • Fichiers servis par Vite        │
│  • MÊME nom de fichier JS           │
│  • ⚠️ Cache possible               │
│  • ✅ Hot reload (parfois)         │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│  npm run build                      │
│  ──────────────                     │
│  • Génère /dist/                   │
│  • Fichiers avec hash (abc123.js)  │
│  • Nom change à chaque build       │
│  • ✅ Pas de cache                 │
│  • Optimisé pour production        │
└─────────────────────────────────────┘
