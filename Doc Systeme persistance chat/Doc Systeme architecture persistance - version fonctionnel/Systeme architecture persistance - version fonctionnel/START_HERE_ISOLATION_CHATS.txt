Problème : Test d'isolation échoue
───────────────────────────────────
Solution 1 : Vider le cache du navigateur
  Ctrl + Shift + Suppr → Effacer les données

Solution 2 : Forcer le rechargement
  Ctrl + F5

Solution 3 : Corriger la synchronisation
  F12 → Console → corrigerSynchronisation()

Problème : Tables mélangées entre chats
────────────────────────────────────────
Solution : Réinitialiser la base de données
  1. F12 → Console
  2. Taper : indexedDB.deleteDatabase('clara_db')
  3. Recharger la page
  4. Relancer les tests

Problème : Erreur "clara_db not found"
───────────────────────────────────────
Solution : Base de données non initialisée
  1. Ouvrir l'application ClaraVerse
  2. Attendre le chargement complet
  3. Retester
