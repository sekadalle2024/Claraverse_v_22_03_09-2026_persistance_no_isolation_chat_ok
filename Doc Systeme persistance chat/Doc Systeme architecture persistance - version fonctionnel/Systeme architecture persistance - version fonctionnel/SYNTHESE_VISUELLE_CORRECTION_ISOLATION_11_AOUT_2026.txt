    2. MÉTHODES API
    ═══════════════

    getAll() - Récupérer toutes les tables
    ───────────────────────────────────────
    AVANT  : getAll()             → Toutes les données ❌
    APRÈS  : getAll(sessionId)    → Données filtrées par chat ✅

    get() - Récupérer une table
    ────────────────────────────
    AVANT  : get(key)             → Par clé simple ❌
    APRÈS  : get(id)              → Par id unique ✅

    set() - Sauvegarder une table
    ──────────────────────────────
    AVANT  : set(key, value)      → 2 paramètres ❌
    APRÈS  : set(table)           → Objet avec id + sessionId ✅

    remove() - Supprimer une table
    ───────────────────────────────
    AVANT  : remove(key)          → Par clé simple ❌
    APRÈS  : remove(id)           → Par id unique ✅
             removeBySession(id)  → Tout un chat ✅ NOUVEAU
