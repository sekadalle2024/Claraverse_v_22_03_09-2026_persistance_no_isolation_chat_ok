┌────────────────────────────────────────────────────────────────────┐
│  SYMPTÔMES OBSERVÉS                                                │
└────────────────────────────────────────────────────────────────────┘

❌ Les tables sont générées et affichées CORRECTEMENT
❌ MAIS elles disparaissent après :
   - Un rechargement de page (F5)
   - Un changement de chat
   - Une fermeture/réouverture du navigateur


┌────────────────────────────────────────────────────────────────────┐
│  CAUSES POSSIBLES                                                  │
└────────────────────────────────────────────────────────────────────┘

🔴 PROBLÈME 1 : Tables non sauvegardées dans localStorage
   → Les tables sont générées en mémoire mais jamais persistées

🔴 PROBLÈME 2 : Format de sauvegarde incorrect
   → Les tables sont sauvegardées mais dans un format non récupérable

🔴 PROBLÈME 3 : Écrasement lors de la restauration
   → Les tables sont sauvegardées mais perdues au rechargement

🔴 PROBLÈME 4 : Problème de timing
   → Les tables disparaissent avant d'être sauvegardées

   const messages = JSON.parse(localStorage.getItem(`flowise_messages_${chatId}`));
   console.log('Messages sauvegardés:', messages);
   
   // Chercher les tables dans les messages
   messages.forEach((msg, idx) => {

═══════════════════════════════════════════════════════════════════
   SOLUTIONS SELON LE DIAGNOSTIC
═══════════════════════════════════════════════════════════════════

SI flowiseTableBridge est undefined :
→ Problème d'import du service dans index.html

SI les clés localStorage sont vides :
→ Problème de sauvegarde initiale

SI les messages existent mais sans tables :
→ Problème de sérialisation HTML

SI les messages disparaissent au rechargement :
→ Problème de restauration

SI les tables sont là mais non affichées :
→ Problème de rendu frontend
