📋 PROBLÈME IDENTIFIÉ
─────────────────────
Lorsqu'un utilisateur ouvre plusieurs chats différents, les tableaux d'une session 
écrasent les tableaux d'une autre session, créant une confusion visuelle.

🎯 HYPOTHÈSES PRINCIPALES
──────────────────────────
✅ H1: Les tableaux restaurés n'ont pas d'attribut `data-session-id`
   → Solution: Ajouter l'attribut lors de la restauration

✅ H2: Le nettoyage du DOM ne filtre pas par sessionId
   → Solution: Filtrer strictement par sessionId dans clearAllTablesFromDOM()

✅ H3: Pas de vérification après restauration
   → Solution: Logger le nombre de tableaux avec le bon sessionId

✅ H4: Difficile de tracer les sauvegardes
   → Solution: Logger toutes les sauvegardes avec sessionId/keyword

APRÈS:
  private async clearAllTablesFromDOM(sessionId?: string): Promise<number> {
    // Ajoute un filtre par sessionId
    tables.forEach(table => {
      if (sessionId) {
        const tableSessionId = table.getAttribute('data-session-id');
        if (tableSessionId && tableSessionId !== sessionId) {
          // Ne pas supprimer les tables d'une autre session
          return;
        }
      }
      table.remove();
      totalCleared++;
    });

Impact: Ne supprime que les tableaux de la session courante, préservant les autres.
