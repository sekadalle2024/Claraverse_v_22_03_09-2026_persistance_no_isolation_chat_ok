📍 PROBLÈME IDENTIFIÉ
━━━━━━━━━━━━━━━━━━━━
▸ Les tables [Modelised_table] du chat précédent apparaissent dans le nouveau chat
▸ Les données du nouveau chat disparaissent pour laisser place à l'ancien
▸ Cause : sessionId stable ne change pas entre les chats

✅ SOLUTION
━━━━━━━━━━
▸ Système de double identifiant :
  • chatId  : Unique par conversation (isole les chats)
  • sessionId : Stable (pour restauration unique)
  • Clé composite : chatId_sessionId
