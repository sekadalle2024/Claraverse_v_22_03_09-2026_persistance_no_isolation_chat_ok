PROBLÈME 1 : "This site can't be reached"
──────────────────────────────────────────────────────────────

→ Le serveur ne tourne pas

Solution :
  • Vérifiez que npm run dev est bien lancé
  • Regardez le message dans le terminal
  • Vérifiez qu'il n'y a pas d'erreur


PROBLÈME 2 : Page blanche
──────────────────────────────────────────────────────────────

→ Erreur JavaScript ou cache

Solution :
  1. F12 → Console → Regardez les erreurs
  2. Ctrl + Shift + Delete → Effacer le cache
  3. Recharger : Ctrl + Shift + R


PROBLÈME 3 : ERR_CONNECTION_REFUSED
──────────────────────────────────────────────────────────────

→ Le port est bloqué ou le serveur n'a pas démarré

Solution :
  1. Vérifiez : netstat -ano | findstr :5173
  2. Si rien n'apparaît, le serveur ne tourne pas
  3. Relancez : npm run dev


PROBLÈME 4 : "Cannot GET /"
──────────────────────────────────────────────────────────────

→ Problème de routing

Solution :
  • Le serveur tourne mais il y a un problème de config
  • Vérifiez que index.html existe
  • Essayez : http://127.0.0.1:5173/index.html
