═══════════════════════════════════════════════════════════════════
   PROBLEMES FREQUENTS ET SOLUTIONS
═══════════════════════════════════════════════════════════════════

❌ "localStorage is not defined"
   → Le navigateur bloque localStorage
   → Désactivez le mode navigation privée
   → Vérifiez les paramètres du navigateur

❌ "CORS error"
   → Problème de configuration backend
   → Vérifiez que Flowise est accessible

❌ "Cannot read property 'messages'"
   → Service flowiseTableBridge non initialisé
   → Vérifiez les imports dans index.html

❌ Chats disparaissent au rechargement
   → Problème de sauvegarde dans localStorage
   → Vérifiez que les clés "flowise_*" existent
