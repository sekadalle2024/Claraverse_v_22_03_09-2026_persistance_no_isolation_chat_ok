┌─────────────────────────────────────────────────────────────┐
│ MÉTHODE 3: Tests Manuels dans ClaraVerse                    │
└─────────────────────────────────────────────────────────────┘

1. Démarrer ClaraVerse:
   npm run dev

2. Ouvrir: http://localhost:5173

3. Ouvrir console (F12)

4. Suivre les 4 scénarios de test:

   ┌─ Test 1: ORDRE DES TABLES ─────────────────────┐
   │ • Créer table Modelised                        │
   │ • Faire consolidation                          │
   │ • Vérifier ordre: Conso → Résultat → Model    │
   └────────────────────────────────────────────────┘

   ┌─ Test 2: PERSISTANCE ──────────────────────────┐
   │ • Modifier des cellules                        │
   │ • Recharger page (F5)                          │
   │ • Vérifier tout est restauré                   │
   └────────────────────────────────────────────────┘

   ┌─ Test 3: ISOLATION ────────────────────────────┐
   │ • Chat A: créer tables "DATA-A"                │
   │ • Chat B: créer tables "DATA-B"                │
   │ • Retour Chat A: vérifier "DATA-A" seulement   │
   └────────────────────────────────────────────────┘

   ┌─ Test 4: PROTECTION ───────────────────────────┐
   │ • Créer nouvelle table                         │
   │ • Observer logs: "🛡️ Table protégée"          │
   │ • Confirmer pas de suppression < 5s            │
   └────────────────────────────────────────────────┘

✅ Validation réelle | ✅ Test complet

□ Ordre: Tables toujours Conso → Résultat → Modelised
□ Persistance: Tables restaurées après F5 avec données
□ Isolation: Pas de mélange entre Chat A et Chat B
